SM NLO provenance: the param_card defect, measured and fixed

    MadSpin's density path used to initialise its standalone matrix-element
    library from <madspin_me>/Cards/param_card.dat -- the card `output
    standalone' wrote from the MODEL DEFAULTS -- and never from the run's own
    card.  For PROC_sm_nlo that meant

        run :  MT 172.76   WT 1.33     WZ 2.4952   WW 2.085
        ME  :  MT 173.0    WT 1.4915   WZ 2.4414   WW 2.0476

    a top mass 0.24 GeV too high and a top width 12 % too large in the density
    matrix.  The defect was real.  It is fixed (0a1007bc2), and the sm_nlo
    sample plotted here was regenerated with the fix (T123), reusing the same
    500k production events at the same MadSpin seeds -- so the comparison
    below is exact and not Monte-Carlo noise in the production.

    The measured effect on this observable is nil:

      rate   10.9004361 -> 10.9004235 pb, i.e. -0.0001 %, against a 0.020 pb
             integration error.  The <init> XSECUP is 10.899373 +- 0.020274 pb
             before and after, to every digit the banner carries.

      shape  below the reseeding noise floor.  Buggy against fixed moves the
             Delta phi forward-backward asymmetry by +0.0076; changing only
             the MadSpin seed, 42 -> 99, with the fixed code moves it by
             -0.0050; buggy against that seed-99 run, by +0.0025.  The 720-bin
             chi2/ndf is 1.002, 0.975 and 0.997 for the three pairings: all
             equally indistinguishable.

    So `immaterial' here is a measurement, not a hope.  spinmode = none was
    never affected -- it builds no density matrix, has no madspin_me directory,
    and its histograms reproduced bit for bit.  The two LO samples differ from
    their ME card only in alpha_s(M_Z) (0.1190025 against 0.1179), which
    cancels exactly in MadSpin's Tr(rho_prod)-normalised accept/reject
    weight.

    The regeneration (task T123, branch claude/ms-smeft-fig5-nlo-redo) needed
    no change to this script: nothing about the samples is hard-coded here,
    every cross section, weight and curve being read out of the histogram file
    and its meta.json.  Dropping a new data/histograms.npz in place and
    re-running is all a further regeneration would take.

  On this figure the defect was in the DENSITY path, which spinmode =
  none does not use.  Pane 2 is now onshell only, so it is entirely
  built from curves the defect could in principle have touched; the
  measured move is 0.83 % at most, 1.8 sigma, below the seed noise.

the third curve that was asked for: (NLO + K*int)/NLO, K = NLO/LO
------------------------------------------------------------------------------
  K(x) = dsigma_NLO(x)/dsigma_LO(x) gives

      dsigma_NLO + K dsigma_int = dsigma_NLO * [1 + dsigma_int/dsigma_LO]

  so dsigma_NLO cancels and the ratio to dsigma_NLO is
  1 + dsigma_int/dsigma_LO -- which IS (LO + int)/LO.

  rate convention  : max |(NLO + K int)/NLO  -  (LO + int)/LO| = 0.0e+00
                     (an exact algebraic identity, not a small number)
  shape convention : curve3/curveLO = (1 + w_LO)/Z, with no x in it
                     w_LO = -0.27509208   Z = 0.72382273
                     ratio = 1.0014992469 in every bin, spread 2.2e-16
                     max separation 0.001600 = 0.91 x the plotted error

  So the rate-K curve is the LO curve rescaled by a CONSTANT 0.1499 %,
  from nothing but renormalising the K-weighted sum to unit area.  It
  carries no shape information and is NOT drawn on O.  Read the LO
  curve as the NLO estimate under a bin-by-bin K-factor ansatz instead;
  that belongs in the caption.

  Only the x-dependence of K can move the curve.  Splitting
  K(x) = <K> k(x) with <K> = sigma_NLO/sigma_LO = 1.5192 and <k> = 1:
    <K> rescales the interference rate, which is the same knob as c_tG
        (scanned in G-N) and divides back out in the shape convention;
    k(x) = n_NLO/n_LO is the only part that is not already on the pane.

  (NLO + k int)/NLO with k = n_NLO/n_LO -- variation P -- is distinct:
      6.35 sigma from the NLO curve at its furthest bin
      15.54 sigma from the LO curve
      between the two in 17 of the 20 bins
      ends +0.9753 +- 0.0018  ...  +1.0402 +- 0.0010
