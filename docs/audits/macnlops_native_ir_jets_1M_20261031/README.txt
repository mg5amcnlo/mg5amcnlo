Native-history MC@NLO-Delta multijet validation, 31 October 2026

Completed 1,000,000 freshly generated events each for e+e -> 2j/3j/4j
and pp -> W+1j, with first-emission matching and full showers. All four
samples pass computational, probability, scale and weight-accounting
checks. Transfer cancellation remains imperfect; report.txt records
both the residuals and the limits of the uncertainty estimates. Wj has
151 first-step and 5,097 full-shower native ISR weight-above-unity warning
occurrences; their impact is unquantified and is not covered by sampling
errors. validation/shower_warnings.json pins all counts and original logs.

The eight-page PDF compares the source, S-veto, H-removal and combined
weights before and after showering. The complete JSON histogram file remains in the external campaign; this
repository subset retains the PDF and numeric transfer/normalization summaries. validation/ contains the
numeric, migration, scale, source-epoch and provenance summaries.
The optional parent/gluon-bound diagnostics do not establish a cause
for the measured deficits. inputs/ contains actual cards, profiles and
full-shower commands. Card whitespace is normalized without changing
any tokens; snapshot.json pins the external raw originals and copies.

Accepted source epochs are explicit: EE2j/EE3j use the pre-packing-fix
source, valid because every emitted index is last; Wj/EE4j were fully
regenerated with the compact-Born fix before unweighting. Invalid older
partial runs remain external and are not included in these results.
