# Building the docs locally

## 1. Install prerequisites

Install doxygen (via your system/package manager of choice), then:

```bash
pip install -r docs/requirements.txt
```

## 2. Build madspace with docstrings enabled

The Python API reference is generated by importing the built `madspace`
extension, and its docstrings only exist when it's built with
`ENABLE_DOCS=ON` (needs doxygen on `PATH`):

```bash
python madspace/install.py --source --docs -y
```

Use `--source` (not a plain `-y`, which installs the stale PyPI wheel) so the
docs track your working tree.

## 3. Build the HTML

```bash
PYTHONPATH=madspace/install DOCS_VERSION=local make -C docs html
```

`DOCS_VERSION` is only used to label the (hidden, since there's no
`versions.json` locally) version switcher; it can be omitted.

Check the build log for `generate_api_pages: wrote N C++ and M Python pages`
— low numbers usually mean doxygen didn't run or `import madspace` failed.

## 4. Serve it

```bash
python -m http.server -d docs/build/html
```

then open http://localhost:8000/.
